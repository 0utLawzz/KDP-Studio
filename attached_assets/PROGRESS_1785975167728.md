## Known Issues / Gotchas

1. **Zod integer vs number** – OpenAPI must use `type: number` (not `integer`) because project uses Zod v3.
2. **Generated files** – Never edit files under `lib/*/src/generated/` manually; re-run codegen.
3. **Python path** – API spawns `python3`; ensure reportlab is installed for that interpreter.
4. **Minimum pages** – Full-color interiors are padded with blank notes pages to reach 72 pages.
5. **Cover spine text** – KDP only allows spine text at 79+ pages; thinner spines get solid color only.
6. **Always verify** cover size in the [official KDP Cover Calculator](https://kdp.amazon.com/cover-calculator) before publishing.
