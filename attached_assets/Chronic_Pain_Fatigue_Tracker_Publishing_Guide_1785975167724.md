## 2. Design System

**Color Palette (shifted, same brand DNA — gentle/low-stimulation on purpose):**
- Lavender (unchanged): `#E6D9F7`
- Soft Grey-Blue: `#DCE3EA` (new — represents "low energy / rest day")
- Mint (unchanged): `#D6F3E8`
- Peach (unchanged, used sparingly): `#FFE3D1`
- Text (dark plum, unchanged): `#4A3F55`

**Fonts:** Helvetica-Bold (headings), Helvetica (body). Consider slightly larger body text (11-12pt vs standard 10pt) — many chronic pain/fatigue buyers deal with eye strain or fine-motor difficulty; this is a genuine accessibility upgrade, not just a design preference.

**Icon set (new — "sab thora sa" design upgrade):** a small battery/spoon icon (energy level), a flame icon (flare-up), a pill icon (medication), a moon icon (rest/sleep).

## 3. Interior Structure

`title_page` → `intro_page` ("How to Use") → `symptom_tracker_page(s)` for 60 days → `daily_page` (loop x60) → `weekly_review_page` (every 7 days) → pad with `blank_notes_page` if under 72-page minimum.

**Daily page fields (replacing ADHD-specific fields):**
- Today's Focus (kept — still useful for pacing goals)
- Top 3 Priorities (reframed as "Top 3 Gentle Goals" to avoid overwhelm)
- Time Blocks (6 AM–9 PM, same structure, but framed as "Energy Map" — note high/low energy windows instead of task scheduling only)
- Pain Level (scale 1-10) — replaces general Mood, but keep a small secondary Mood row too
- Energy/Spoon Level (Full / Good / Low / Empty)
- Check-in: Medication taken · Water (8 cups) · Rest/pacing break taken · Sleep quality
- Symptom flare note (short line: "What triggered today's flare, if any?")
- Notes

**Weekly Review page (unchanged structure, reframed language):**
- What went well this week?
- What was challenging?
- One pacing adjustment for next week
- Wins to celebrate (kept — important for morale in chronic illness journaling)

All technical margin/bleed/spine rules from the base guideline apply unchanged (0.4in margin, no edge-to-edge banners, spine text only at 79+ pages, 72-page minimum for color).

## 7. Notes Specific to This Topic

- This niche is under-served on Amazon compared to ADHD/anxiety — lower competition, but also lower search volume. Good "second book" pick for steady, low-competition sales.
- "Spoon theory" language ("spoonie") is well-known and searched within this community — worth testing as a keyword and possibly a subtle icon motif, but don't over-explain it in the cover copy (buyers who know it will recognize it; buyers who don't will still understand "pain and energy tracker").
- Keep visual stimulation low — no busy patterns or high-contrast clutter. Many buyers in this niche are managing light/visual sensitivity alongside their primary condition.
