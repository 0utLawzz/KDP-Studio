# KDP Book Studio

Captures the proven rules, design system, and hard-won lessons from building and publishing real books on Amazon KDP under the "Bright Mindful Pages" brand. Treat everything in this file as tested law, not suggestions — every rule here came from an actual KDP rejection or approval, not a guess.

## Brand Context

- **Publisher/Author name on KDP:** Bright Mindful Pages
- **Business model:** Low-content and medium-content books (planners, journals, trackers) — NOT full ebooks. This is deliberate: it avoids the cost/complexity of hiring writers and clearing copyright/publishing rights. Every product must be either structured low-content (repetitive templates: journals, planners, trackers) or medium-content that is 100% originally generated by the system — never scraped or copied.
- **Published books so far:**
  - BMP-001 — ADHD Daily Planner (60-day, lavender_mint palette, 73 pages)
  - BMP-002 — Sobriety & Recovery Daily Tracker (90-day, sage_teal palette)
- **Planned/example niches:** Chronic Pain & Fatigue Tracker (guideline written, not yet built)

## KDP Technical Rules (never violate these)

1. **Margin = 0.4in on all sides.** Nothing — no shape, text, or background banner — may touch or cross x=0, y=0, PAGE_W, or PAGE_H. This is the #1 cause of rejection ("No Bleed" margin violations). All decorative banners must be inset within the margin box, never edge-to-edge.
2. **Minimum page count:** 72 pages for Standard/Premium Color interior; lower for Black & White (confirm current KDP rule if switching ink type). Plan day-count accordingly — pad with blank notes pages if under minimum.
3. **Spine text only allowed at 79+ pages.** Below that: color fill only, no spine text.
4. **Bottom margin buffer:** verify the lowest element on every page sits at least 0.05–0.1in above the bottom margin before finalizing.
5. **No footer/page numbers** unless confirmed to sit within the margin box — these have caused rejections before (removed entirely from the daily page template as the fix).
6. Small circular/graphic elements positioned near the margin line must be offset by their radius so they don't clip past it even by 1pt.

## KDP Listing Rules (title/subtitle/keywords)

- **Format is always Paperback**, never Kindle eBook — fillable planner content doesn't work on eBook (reflowable text, no writing support). Confirm this every time before publishing.
- **Title/Subtitle — CRITICAL LESSON:** Do not list multiple features in the subtitle (e.g. "...with Time Blocking, Mood Tracker & Habit Tracker for Focus and Productivity"). This got a real book flagged for "unnecessary repetitive terms/phrases" (keyword stuffing) by Amazon's content review, with a 5-day fix deadline. Subtitle should state ONE core value proposition in a single clause (e.g. "A 60-Day Undated Planner for Focus and Productivity"). Feature lists belong in the description only, never the title/subtitle — and never on the cover image either (the cover text must match this rule too, it's also customer-facing).
- **7 keywords:** all lowercase, no punctuation, each in its own KDP field. Format pattern: `[condition/topic] planner for adults`, `daily planner for [topic]`, `undated planner [topic]`, `[core feature] journal`, `[feature] tracker`, `[format] planner`, `[audience] planner`.
- **Categories:** must be picked from KDP's *actual* live dropdown for the account — generic guesses (e.g. assuming "ADD/ADHD" exists as a category) are often wrong. Always verify against the real dropdown before finalizing.
- **ISBN:** publish without one (free KDP option) unless the user already owns one.
- **Low-content book checkbox:** Yes, if it's a journal/planner/tracker. **Large-print checkbox:** only if body text is consistently ≥16pt.
- **AI-generated content disclosure:** Yes for Text and Images (the interior/cover design is AI/script-generated). Do NOT mark "Translations" as Yes unless the book actually contains translated content — this was a real mistake caught once.

## 2026 Market Rules (policy risk — check before generating variants)

- Amazon actively suppresses/removes books that look like mass-generated duplicates: same interior with only the cover color changed is a real suppression risk as of 2026.
- **Correct approach to "variations":** either (a) genuinely different niches/topics, or (b) the same book with structurally different sections/content — not just a palette swap. Multiple books is still a fine strategy; copy-paste-with-new-color is not.
- Low-content is maturing toward requiring more differentiation and quality; medium-content (real structure, guided prompts, genuine value) is the more durable long-term direction, not pure repetitive templates.

## Publishing Checklist (run through this every time before submitting)

- [ ] Interior PDF: page count ≥ 72 (color) confirmed
- [ ] Interior PDF: no element touches page edge (margin-safe)
- [ ] Cover PDF: matches KDP Cover Calculator's exact dimensions for the FINAL page count (recalculate if page count changed since last time — spine width changes with page count)
- [ ] Subtitle/description page-count references match the actual interior
- [ ] Subtitle has no feature-list keyword stuffing (see rule above)
- [ ] Categories selected from the real, current KDP dropdown
- [ ] AI content disclosure = Yes for Text/Images, NOT for Translations (unless applicable)
- [ ] Price set after checking 5–10 live competitor listings
- [ ] Format = Paperback confirmed (not Kindle eBook)
- [ ] Upload → Print Previewer → check margin/font errors → Approve

## Common Errors & Fixes (from real rejections)

| Error | Cause | Fix |
|---|---|---|
| "Interior must have minimum X pages" | Page count below ink-type minimum | Add days/content or padding pages |
| "Text/object outside margins" | Edge-to-edge color banner or element sitting exactly at the margin line | Inset all backgrounds by MARGIN; verify with a coordinate check before generating the full file |
| "Fonts not properly embedded" | Standard fonts not auto-embedded | Informational only — KDP embeds automatically, not blocking, safe to ignore if the Approve button is active |
| Spine text rejected | Book under 79 pages | Remove spine text, use color fill only |
| "Misleading customer experience" / title flagged | Subtitle lists multiple features (keyword stuffing) | Simplify subtitle to one clause; also check cover text, not just the KDP metadata field |

## KDP Business Mechanics (for reference when asked)

- **Royalty (Paperback):** 60% if list price ≥ $9.99, else 50% (tiered rule as of mid-2025). Royalty = (List Price × rate) − Printing Cost. B&W printing: $0.85 + $0.012/page. Premium Color: $1.00 + $0.07/page — color books have much thinner margins, factor this into pricing.
- **Kindle eBook royalty:** 70% for $2.99–$9.99 price range, else 35%.
- **Payment timing:** ~60 days after the month of sale (90 days for Expanded Distribution) — first payment takes roughly 2 months to arrive.
- **Research method:** manual Amazon browsing (category browse, reviews count, "bought in past month" badge, BSR) + Publisher Rocket (paid, legal tool) + Google Trends + KDP's own "Book Trends Data." **Never scrape Amazon** — violates ToS, risks account suspension.
